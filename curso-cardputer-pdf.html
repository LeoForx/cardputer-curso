M1

Conhecendo o Hardware

ESP32-S3, especificacoes, pinout e todos os componentes do Cardputer

Fase 1 · Iniciante

Especificacoes Tecnicas

  • MCU: ESP32-S3FN8 — dual-core Xtensa LX7 @ 240 MHz
  • Memoria: 8 MB PSRAM + 8 MB Flash integrada
  • Display: ST7789V2 TFT 1.14" — 135 x 240 pixels, interface SPI
  • Teclado: 56 teclas QWERTY com teclas de funcao e numeros
  • Audio: Speaker interno 1W (I2S) + Microfone PDM SPM1423
  • Wireless: WiFi 802.11 b/g/n 2.4GHz + BLE 5.0
  • IR: Emissor infravermelho 940nm no GPIO44
  • Bateria: 120mAh interna + slot para bateria externa ate 2000mAh
  • USB: USB-C com conversor CH9102F para programacao e carga
  • Expansao: Conector M5Stack Bus + header GPIO na parte inferior
Dica de Inicializacao

M5Cardputer.begin(cfg, true) inicializa todos os perifericos. O parametro 'true' ativa a rotacao correta do display para o Cardputer. Sempre inclua esta linha no setup().

Exercicio

Compile e grave o codigo ao lado. O display deve mostrar as informacoes do chip. Adicione tambem o endereco MAC WiFi usando WiFi.macAddress() apos incluir WiFi.h.

Configurando o Ambiente

Arduino IDE 2.x, driver USB, suporte ESP32 e bibliotecas M5Stack

Fase 1 · Iniciante

Passo a Passo

  • 1. Arduino IDE 2.x — Baixe em arduino.cc. Instale a versao 2.x.
  • 2. Driver CH9102F — Windows: wch.cn. macOS/Linux: automatico.
  • 3. URL do Board Package — Em Preferences, adicione:
    https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
  • 4. Instalar ESP32 Core — Boards Manager > "esp32 by Espressif" > versao 3.x.
  • 5. Biblioteca M5Cardputer — Library Manager > "M5Cardputer" > Instalar.
  • 6. Board — Tools > Board > esp32 > M5Stack-Cardputer
  • 7. Porta — Tools > Port > porta COM (Windows) ou /dev/cu.* (macOS)
  • 8. Upload Speed — Tools > Upload Speed > 921600
Aviso — Upload Falhou?

Se "Failed to connect", mantenha pressionada a tecla 'G' no Cardputer durante o upload. Isso ativa o modo bootloader forcado do ESP32-S3.

Exercicio

Apos instalar tudo, grave o codigo de teste ao lado. O display deve piscar alternando entre preto e azul a cada 500ms.

Hello World no Display

TFT ST7789V2, cores, fontes, cursores e primeiro programa visual

Fase 1 · Iniciante

Conceito

O display TFT tem resolucao 135x240 pixels. O ponto (0,0) fica no canto superior esquerdo. Metodos principais:

  • fillScreen(cor) — limpa a tela
  • setTextColor(cor) — cor do proximo texto
  • setTextSize(n) — tamanho 1=6x8, 2=12x16, 3=18x24
  • setCursor(x, y) — posiciona cursor
  • print/printf — escreve texto
Aviso

Sem fillScreen() antes de nova escrita, o texto antigo permanece. Use fillRect(x,y,w,h,BLACK) para limpar areas especificas.

Exercicio

Exiba seu nome em setTextSize(3) no centro da tela (aprox. x=67 para texto grande) e abaixo mostre a porcentagem da bateria em tempo real no loop().

Display Avancado — Sprites e Formas

Primitivas graficas, sprites para animacao suave e cores personalizadas

Fase 1 · Iniciante

Conceito

M5GFX oferece primitivas graficas completas. Sprites sao buffers em PSRAM que eliminam flickering em animacoes (double buffering): desenha no sprite, depois pushSprite() copia de uma vez para o display.

Cores RGB

Use color565(r, g, b) para qualquer cor. Exemplo: color565(255,128,0) = laranja. Constantes: WHITE, BLACK, RED, GREEN, BLUE, CYAN, YELLOW, MAGENTA.

Lendo o Teclado

Eventos de tecla, leitura de caracteres, input de texto e teclas especiais

Fase 1 · Iniciante

Conceito

O teclado comunica via I2C. Sempre chame M5Cardputer.update() no loop(). isChange() indica mudanca de estado; isPressed() indica tecla ativa. KeysState tem: word (chars), del (backspace), enter, tab, fn (ESC).

Aviso Critico

update() e OBRIGATORIO no loop(). Sem ele, o teclado nunca reporta eventos. Tambem atualiza IMU e outros perifericos.

Exercicio

Adicione um contador de caracteres "32/100" no canto superior direito que atualiza em tempo real. Limite o input a 100 caracteres.

Codigo — Editor de Texto

#include <M5Cardputer.h> String input = ""; void redraw() { M5Cardputer.Display.fillScreen(BLACK); M5Cardputer.Display.setTextColor(CYAN); M5Cardputer.Display.setCursor(0, 5); M5Cardputer.Display.println("Digite (FN=limpar):"); M5Cardputer.Display.setTextColor(WHITE); M5Cardputer.Display.setCursor(0, 20); M5Cardputer.Display.print(input + "|"); } void setup() { auto cfg = M5.config(); M5Cardputer.begin(cfg, true); redraw(); } void loop() { M5Cardputer.update(); // OBRIGATORIO! if (M5Cardputer.Keyboard.isChange() && M5Cardputer.Keyboard.isPressed()) { auto st = M5Cardputer.Keyboard.keysState(); for (auto c : st.word) input += c; if (st.del && input.length() > 0) input.remove(input.length() - 1); if (st.enter) input += "\n"; if (st.fn) input = ""; redraw(); } }

LED e Som Basico

Speaker interno I2S, tonos musicais, melodias e feedback sonoro

Fase 1 · Iniciante

Conceito

O speaker usa I2S gerenciado pela M5Unified. tone(freq, dur_ms) gera beep; mute() para. setVolume(0-255) ajusta o volume. As frequencias musicais: Do=262Hz, Re=294Hz, Mi=330Hz, Fa=349Hz, Sol=392Hz, La=440Hz.

Dica — WAV

Speaker.playRaw(samples, count, rate, stereo, channel, repeat) reproduz audio PCM 16-bit. Armazene arrays de amostras em PROGMEM para notificacoes sonoras customizadas sem usar SPIFFS.

Bateria e Energia

PMIC AXP2101, leitura de bateria, carga e deep sleep com wakeup

Fase 1 · Iniciante

Conceito

O AXP2101 gerencia a bateria e carga via M5Cardputer.Power. Deep sleep consome ~10 uA. RTC_DATA_ATTR preserva variaveis durante o sleep. O setup() e reexecutado apos cada wakeup.

Consumo em cada modo

Ativo WiFi: ~100-250mA. Loop simples: ~40mA. Light sleep: ~2mA. Deep sleep: ~0.01mA. Com bateria de 120mAh, em deep sleep o Cardputer dura mais de 500 dias.

Exercicio

Calculadora com Display

Projeto final da Fase 1 — integra teclado, display e logica de calculo

Fase 1 · Projeto

Objetivos

  • Receber expressoes matematicas pelo teclado (ex: 12+34)
  • Exibir a expressao atual e resultado anterior no display
  • Suportar operacoes: + - * / com numeros decimais
  • Tratar divisao por zero com mensagem de erro e beep
  • Tecla DEL apaga ultimo caractere; FN limpa tudo

Codigo Completo

#include <M5Cardputer.h> String expr = ""; float result = 0; bool hasResult = false; void draw() { auto& d = M5Cardputer.Display; d.fillScreen(0x0A0F1A); d.fillRect(0, 0, 135, 18, 0x0D3A6E); d.setTextColor(CYAN); d.setTextSize(1); d.setCursor(5, 5); d.print("Calculadora Cardputer"); if (hasResult) { d.setTextColor(0x4499FF); d.setTextSize(1); d.setCursor(5, 25); d.printf("= %.4g", result); } d.setTextColor(WHITE); d.setTextSize(2); d.setCursor(5, 45); String disp = expr.length() > 0 ? expr : "0"; if (disp.length() > 9) disp = disp.substring(disp.length()-9); d.print(disp + "|"); d.setTextColor(0x334455); d.setTextSize(1); d.setCursor(0, 115); d.print(" ENTER=calc DEL=apagar FN=limpar"); } float calc(String e) { int pos = -1; char op = 0; for (int i=e.length()-1; i>0; i--) if (e[i]=='+'||e[i]=='-') { pos=i; op=e[i]; break; } if (pos==-1) for (int i=e.length()-1; i>0; i--) if (e[i]=='*'||e[i]=='/') { pos=i; op=e[i]; break; } if (pos==-1) return e.toFloat(); float a=e.substring(0,pos).toFloat(); float b=e.substring(pos+1).toFloat(); if (op=='+') return a+b; if (op=='-') return a-b; if (op=='*') return a*b; if (op=='/') return b!=0 ? a/b : NAN; return 0; } void setup() { auto cfg = M5.config(); M5Cardputer.begin(cfg, true); draw(); } void loop() { M5Cardputer.update(); if (M5Cardputer.Keyboard.isChange() && M5Cardputer.Keyboard.isPressed()) { auto st = M5Cardputer.Keyboard.keysState(); for (auto c : st.word) if ((c>='0'&&c<='9')||c=='.'||c=='+'||c=='-'||c=='*'||c=='/'){ if (hasResult) { expr=""; hasResult=false; } expr += c; } if (st.del && expr.length()>0) expr.remove(expr.length()-1); if (st.enter && expr.length()>0) { result = calc(expr); hasResult = true; if (isnan(result)) { M5Cardputer.Display.fillScreen(RED); M5Cardputer.Display.setCursor(30,60); M5Cardputer.Display.print("Erro: div/0!"); M5Cardputer.Speaker.tone(200, 300); delay(1500); hasResult=false; expr=""; } } if (st.fn) { expr=""; hasResult=false; } draw(); } }

WiFi Basico

Scan de redes, conexao, status e informacoes de rede

Fase 2 · Intermediario

Conceito

WiFi.mode(WIFI_STA) ativa modo cliente. scanNetworks() retorna quantidade de redes. WiFi.begin(ssid, pass) inicia conexao. WiFi.status() == WL_CONNECTED indica sucesso. WiFi.localIP() retorna o IP atribuido.

Aviso

O ESP32-S3 suporta APENAS WiFi 2.4 GHz. Redes 5 GHz sao invisiveis. Verifique a faixa da sua rede se ela nao aparecer no scan.

Exercicio

#include <M5Cardputer.h> #include <WiFi.h> const char* SSID = "SUA_REDE"; const char* PASS = "SUA_SENHA"; void setup() { auto cfg = M5.config(); M5Cardputer.begin(cfg, true); auto& d = M5Cardputer.Display; d.fillScreen(BLACK); d.setTextColor(WHITE); d.setTextSize(1); WiFi.mode(WIFI_STA); d.println("Escaneando redes...\n"); int n = WiFi.scanNetworks(); d.printf("%d redes encontradas:\n", n); for (int i = 0; i < min(n, 5); i++) d.printf("%-18s %ddBm ch%d\n", WiFi.SSID(i).substring(0,16).c_str(), WiFi.RSSI(i), WiFi.channel(i)); delay(2000); d.fillScreen(BLACK); d.setCursor(0,0); d.printf("Conectando a %s\n", SSID); WiFi.begin(SSID, PASS); int t = 0; while (WiFi.status() != WL_CONNECTED && t++ < 20) { delay(500); d.print("."); } if (WiFi.status() == WL_CONNECTED) { d.println("\n\nConectado!"); d.println(WiFi.localIP().toString()); d.printf("RSSI: %d dBm\n", WiFi.RSSI()); } else d.println("\nFalha! Verifique SSID/SENHA"); } void loop() {}
