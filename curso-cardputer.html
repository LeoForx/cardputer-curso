O que e o M5Stack Cardputer-ADV?

O Cardputer e um computador de bolso baseado no microcontrolador ESP32-S3 da Espressif. Ele combina teclado QWERTY completo, tela TFT colorida, speaker, microfone, emissor infravermelho e conectividade WiFi/BLE em um dispositivo do tamanho de um cartao de credito ampliado.

  • MCU: ESP32-S3FN8 — dual-core Xtensa LX7 @ 240 MHz
  • Memoria: 8 MB PSRAM + 8 MB Flash integrada
  • Display: ST7789V2 TFT 1.14" — 135 x 240 pixels, SPI
  • Teclado: 56 teclas QWERTY com teclas de funcao
  • Audio: Speaker 1W + Microfone PDM SPM1423
  • Wireless: WiFi 802.11 b/g/n + BLE 5.0
  • IR: Emissor infravermelho 940nm (pino GPIO44)
  • Bateria: 120mAh interna (slot para bateria externa ate 2000mAh)
  • USB: USB-C com CH9102F para programacao e carga
  • Expansao: Conector M5Stack Bus + header GPIO

Codigo — Lendo informacoes do sistema

#include <M5Cardputer.h> void setup() { // Inicializa todos os perifericos do Cardputer auto cfg = M5.config(); M5Cardputer.begin(cfg, true); // Configura o display M5Cardputer.Display.setTextColor(WHITE); M5Cardputer.Display.setTextSize(1); M5Cardputer.Display.setCursor(5, 5); // Exibe informacoes do chip M5Cardputer.Display.println("=== Cardputer Info ==="); M5Cardputer.Display.printf("CPU: %d MHz\n", ESP.getCpuFreqMHz()); M5Cardputer.Display.printf("Flash: %d KB\n", ESP.getFlashChipSize() / 1024); M5Cardputer.Display.printf("PSRAM: %d KB\n", ESP.getPsramSize() / 1024); M5Cardputer.Display.printf("RAM livre: %d KB\n", ESP.getFreeHeap() / 1024); M5Cardputer.Display.printf("Bat: %d%%\n", M5Cardputer.Power.getBatteryLevel()); } void loop() {}
Dica

O metodo M5Cardputer.begin(cfg, true) inicializa o display com orientacao correta para o Cardputer. O segundo parametro 'true' ativa a rotacao automatica. Sem ele, o display aparece de lado.

Passo a Passo de Instalacao

  • 1. Arduino IDE 2.x — Baixe em arduino.cc/en/software. Instale a versao 2.x (nao a 1.8).
  • 2. Driver USB — O Cardputer usa CH9102F. No Windows, baixe em wch.cn. No macOS/Linux e automatico.
  • 3. Board Package ESP32 — Em Preferences, adicione a URL: https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json. Em Boards Manager, instale "esp32 by Espressif Systems" versao 3.x.
  • 4. Biblioteca M5Cardputer — Em Library Manager, busque "M5Cardputer" e instale a versao mais recente da M5Stack.
  • 5. Configurar board — Tools > Board > esp32 > M5Stack-Cardputer
  • 6. Configurar porta — Tools > Port > selecione a porta COM (Windows) ou /dev/cu.* (macOS)
  • 7. Upload speed — Tools > Upload Speed > 921600

Conceito

O display TFT do Cardputer tem resolucao 135x240 pixels com 16-bit de cor (65536 cores). A comunicacao e via SPI a alta velocidade, abstraida pela biblioteca M5GFX. O ponto de origem (0,0) fica no canto superior esquerdo. O eixo X vai ate 134 e o eixo Y ate 239.

  • setCursor(x, y) — posiciona o cursor de texto
  • setTextColor(cor) — define a cor do texto (WHITE, RED, CYAN, etc.)
  • setTextSize(n) — define o tamanho do texto (1=pequeno, 2=medio, 3=grande)
  • print()/println() — escreve texto, igual ao Serial
  • printf() — escreve texto formatado (como printf do C)
  • fillScreen(cor) — preenche toda a tela com uma cor

Conceito

O teclado do Cardputer comunica via I2C com o ESP32-S3. A biblioteca M5Cardputer expoe M5Cardputer.Keyboard com dois metodos principais: isChange() (retorna true quando o estado do teclado mudou) e isPressed() (true se alguma tecla esta pressionada). O struct KeysState contem: word (string com caracteres normais), del (backspace), enter, tab, fn (ESC/funcao).

Codigo — Editor de texto simples

#include <M5Cardputer.h> String input = ""; void redraw() { M5Cardputer.Display.fillScreen(BLACK); M5Cardputer.Display.setTextColor(CYAN); M5Cardputer.Display.setTextSize(1); M5Cardputer.Display.setCursor(0, 5); M5Cardputer.Display.println("Digite (ENTER=nova linha):"); M5Cardputer.Display.setTextColor(WHITE); M5Cardputer.Display.setCursor(0, 20); M5Cardputer.Display.print(input + "|"); // cursor piscante simulado } void setup() { auto cfg = M5.config(); M5Cardputer.begin(cfg, true); redraw(); } void loop() { M5Cardputer.update(); // OBRIGATORIO: atualiza estado do teclado if (M5Cardputer.Keyboard.isChange() && M5Cardputer.Keyboard.isPressed()) { Keyboard_Class::KeysState st = M5Cardputer.Keyboard.keysState(); // Adiciona caracteres normais for (auto c : st.word) input += c; // Backspace (DEL) if (st.del && input.length() > 0) input.remove(input.length() - 1); // Enter: adiciona nova linha if (st.enter) input += "\n"; // FN (ESC): limpa tudo if (st.fn) input = ""; redraw(); } }
Aviso Comum

Sempre chame M5Cardputer.update() no inicio do loop(). Sem ele, o teclado nunca reporta eventos. Este metodo atualiza internamente o estado de todos os perifericos (teclado, IMU, etc.).

Conceito

O Cardputer usa o chip AXP2101 para gerenciamento de energia, acessivel via M5Cardputer.Power. O deep sleep desliga quase todos os circuitos do ESP32-S3 consumindo apenas ~10 uA, ideal para projetos a bateria. Ao acordar, o codigo recomeça do setup() — use RTC_DATA_ATTR para preservar variaveis.

#include <M5Cardputer.h> #include <esp_sleep.h> // RTC_DATA_ATTR: preserva valor durante deep sleep RTC_DATA_ATTR int wakeCount = 0; void setup() { auto cfg = M5.config(); M5Cardputer.begin(cfg, true); wakeCount++; auto& d = M5Cardputer.Display; d.fillScreen(BLACK); d.setTextColor(WHITE); d.setTextSize(1); d.setCursor(5, 5); d.printf("Acordou #%d\n\n", wakeCount); // Nivel da bateria em percentual int bat = M5Cardputer.Power.getBatteryLevel(); bool charging = M5Cardputer.Power.isCharging(); d.printf("Bateria: %d%%\n", bat); d.printf("Carregando: %s\n", charging ? "Sim" : "Nao"); // Barra de bateria int w = map(bat, 0, 100, 0, 120); uint16_t col = bat > 50 ? GREEN : bat > 20 ? YELLOW : RED; d.drawRect(5, 70, 122, 12, WHITE); d.fillRect(6, 71, w, 10, col); d.setCursor(5, 90); d.println("Dormindo em 3s..."); d.println("(qualquer tecla acorda)"); delay(3000); // Acorda com qualquer tecla (GPIO0 = tecla do teclado) esp_sleep_enable_ext0_wakeup((gpio_num_t)0, 0); // OU timer de 30 segundos como backup esp_sleep_enable_timer_wakeup(30 * 1000000ULL); d.fillScreen(BLACK); esp_deep_sleep_start(); // nao retorna } void loop() {} // nunca executado em deep sleep
Dica — Consumo em diferentes modos

Ativo: ~100mA. Light sleep: ~2mA. Deep sleep: ~0.01mA. Com a bateria de 120mAh interna, o Cardputer em deep sleep dura mais de 500 dias. No modo ativo WiFi, apenas ~1.2 horas.

Descricao

Construir uma calculadora funcional que receba expressoes pelo teclado (ex: "12+34"), calcule e exiba o resultado ao pressionar ENTER. Suporta as 4 operacoes basicas, numeros decimais e trata divisao por zero.

Codigo Completo

#include <M5Cardputer.h> String expr = ""; float result = 0; bool hasResult = false; void draw() { auto& d = M5Cardputer.Display; d.fillScreen(0x0A0F1A); // Header d.fillRect(0, 0, 135, 18, 0x0D3A6E); d.setTextColor(CYAN); d.setTextSize(1); d.setCursor(5, 5); d.print("Calculadora Cardputer"); // Resultado anterior if (hasResult) { d.setTextColor(0x4499FF); d.setTextSize(1); d.setCursor(5, 25); d.printf("= %.4g", result); } // Expressao atual d.setTextColor(WHITE); d.setTextSize(2); d.setCursor(5, 45); String disp = expr.length() > 0 ? expr : "0"; if (disp.length() > 9) disp = disp.substring(disp.length() - 9); d.print(disp + "|"); // Instrucoes d.setTextColor(0x334455); d.setTextSize(1); d.setCursor(0, 115); d.print(" ENTER=calc DEL=apagar FN=limpar"); } float calc(String e) { int pos = -1; char op = 0; for (int i = e.length()-1; i > 0; i--) if (e[i]=='+' || e[i]=='-') { pos=i; op=e[i]; break; } if (pos==-1) for (int i = e.length()-1; i > 0; i--) if (e[i]=='*' || e[i]=='/') { pos=i; op=e[i]; break; } if (pos==-1) return e.toFloat(); float a = e.substring(0, pos).toFloat(); float b = e.substring(pos+1).toFloat(); if (op=='+') return a+b; if (op=='-') return a-b; if (op=='*') return a*b; if (op=='/') return b!=0 ? a/b : NAN; return 0; } void setup() { auto cfg = M5.config(); M5Cardputer.begin(cfg, true); draw(); } void loop() { M5Cardputer.update(); if (M5Cardputer.Keyboard.isChange() && M5Cardputer.Keyboard.isPressed()) { Keyboard_Class::KeysState st = M5Cardputer.Keyboard.keysState(); for (auto c : st.word) if ((c>='0'&&c<='9')||c=='.'||c=='+'||c=='-'||c=='*'||c=='/') { if (hasResult) { expr=""; hasResult=false; } expr += c; } if (st.del && expr.length() > 0) expr.remove(expr.length()-1); if (st.enter && expr.length() > 0) { result = calc(expr); hasResult = true; if (isnan(result)) { M5Cardputer.Display.fillScreen(RED); M5Cardputer.Display.setCursor(30, 60); M5Cardputer.Display.print("Erro: div/0"); M5Cardputer.Speaker.tone(200, 300); delay(1500); hasResult=false; expr=""; } } if (st.fn) { expr=""; hasResult=false; } draw(); } }

Codigo — Scan e Conexao

#include <M5Cardputer.h> #include <WiFi.h> const char* SSID = "SUA_REDE"; const char* PASS = "SUA_SENHA"; void setup() { auto cfg = M5.config(); M5Cardputer.begin(cfg, true); auto& d = M5Cardputer.Display; d.fillScreen(BLACK); d.setTextColor(WHITE); d.setTextSize(1); // Modo estacao (cliente) WiFi.mode(WIFI_STA); d.println("Escaneando redes...\n"); int n = WiFi.scanNetworks(); d.printf("%d redes encontradas:\n", n); for (int i = 0; i < min(n, 5); i++) { d.printf("%-18s %ddBm ch%d\n", WiFi.SSID(i).substring(0,16).c_str(), WiFi.RSSI(i), WiFi.channel(i)); } delay(2000); // Conectar a rede especifica d.fillScreen(BLACK); d.setCursor(0,0); d.printf("Conectando a %s\n", SSID); WiFi.begin(SSID, PASS); int t = 0; while (WiFi.status() != WL_CONNECTED && t++ < 20) { delay(500); d.print("."); } if (WiFi.status() == WL_CONNECTED) { d.println("\n\nConectado!"); d.println(WiFi.localIP().toString()); d.printf("RSSI: %d dBm\n", WiFi.RSSI()); } else { d.println("\nFalha! Verifique SSID/SENHA"); } } void loop() {}
Aviso

O ESP32-S3 suporta apenas WiFi 2.4 GHz. Redes 5 GHz sao invisiveis para ele. Se a rede nao aparecer no scan, verifique se ela esta na faixa de 2.4 GHz.

#include <M5Cardputer.h> #include <WiFi.h> #include <HTTPClient.h> #include <ArduinoJson.h> const char* SSID = "SUA_REDE"; const char* PASS = "SUA_SENHA"; void setup() { auto cfg = M5.config(); M5Cardputer.begin(cfg, true); auto& d = M5Cardputer.Display; d.fillScreen(BLACK); d.setTextColor(WHITE); d.setTextSize(1); WiFi.begin(SSID, PASS); while (WiFi.status() != WL_CONNECTED) delay(500); d.println("WiFi OK! Buscando hora...\n"); HTTPClient http; // API publica de horario (sem autenticacao) http.begin("http://worldtimeapi.org/api/timezone/America/Sao_Paulo"); int code = http.GET(); if (code == 200) { String body = http.getString(); JsonDocument doc; deserializeJson(doc, body); String dt = doc["datetime"].as<String>(); int offset = doc["utc_offset"].as<int>(); d.setTextColor(CYAN); d.setTextSize(2); d.setCursor(5, 30); d.println(dt.substring(11, 19)); // HH:MM:SS d.setTextColor(WHITE); d.setTextSize(1); d.setCursor(5, 65); d.println(dt.substring(0, 10)); // YYYY-MM-DD d.printf("Fuso: UTC%+d\n", offset/3600); } else { d.printf("Erro HTTP: %d", code); } http.end(); } void loop() {}

Dica — NVS para guardar tokens com seguranca

Use Preferences.h (NVS — Non-Volatile Storage) para guardar tokens e senhas. O NVS e armazenado em particao separada da flash e nao pode ser lido por um simples dump do firmware. Nao guarde segredos em SPIFFS ou em variaveis globais no codigo.

FreeRTOS e Multitasking

Tasks, semaforos, filas (queues) e comunicacao entre tasks no ESP32-S3

Conceito

O ESP32-S3 tem dois cores (Core 0 e Core 1). O Arduino loop() roda no Core 1. Com FreeRTOS, crie tasks independentes em qualquer core. xQueueCreate/xQueueSend/xQueueReceive implementam comunicacao segura entre tasks (thread-safe). vTaskDelay(pdMS_TO_TICKS(ms)) e o delay correto dentro de tasks — libera o processador durante a espera.

Codigo — Duas tasks em cores diferentes

#include <M5Cardputer.h> #include <WiFi.h> const char* SSID="SUA_REDE", *PASS="SUA_SENHA"; QueueHandle_t queue; // Task no Core 0: coleta dados a cada 2 segundos void taskSensor(void* p) { while(true) { char msg[48]; snprintf(msg,sizeof(msg),"BAT:%d%% RSSI:%ddBm", M5Cardputer.Power.getBatteryLevel(), WiFi.RSSI()); xQueueSend(queue, msg, 0); // nao bloqueia se fila cheia vTaskDelay(pdMS_TO_TICKS(2000)); } } // Task no Core 1: exibe no display quando recebe mensagem void taskDisplay(void* p) { char msg[48]; int y=20; while(true) { if(xQueueReceive(queue, msg, portMAX_DELAY)) { M5Cardputer.Display.setTextColor(WHITE, BLACK); M5Cardputer.Display.setCursor(0,y); M5Cardputer.Display.println(msg); y+=12; if(y>120){y=20;M5Cardputer.Display.fillRect(0,20,135,100,BLACK);} } } } void setup() { auto cfg=M5.config(); M5Cardputer.begin(cfg,true); auto& d=M5Cardputer.Display; d.fillScreen(BLACK); d.setTextColor(CYAN); d.setTextSize(1); d.setCursor(0,0); d.print("FreeRTOS Dual-Core"); WiFi.begin(SSID,PASS); while(WiFi.status()!=WL_CONNECTED)delay(500); // Fila de 5 mensagens de 48 bytes queue = xQueueCreate(5, 48); // xTaskCreatePinnedToCore(funcao, nome, stack, param, prioridade, handle, core) xTaskCreatePinnedToCore(taskSensor, "sensor", 4096, NULL, 1, NULL, 0); xTaskCreatePinnedToCore(taskDisplay, "display",4096, NULL, 1, NULL, 1); } void loop() { vTaskDelay(pdMS_TO_TICKS(1000)); } // loop idle
