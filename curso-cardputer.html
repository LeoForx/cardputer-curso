O que e o M5Stack Cardputer-ADV?

O Cardputer e um computador de bolso baseado no microcontrolador ESP32-S3 da Espressif. Ele combina teclado QWERTY completo, tela TFT colorida, speaker, microfone, emissor infravermelho e conectividade WiFi/BLE em um dispositivo do tamanho de um cartao de credito ampliado.

  • MCU: ESP32-S3FN8 — dual-core Xtensa LX7 @ 240 MHz
  • Memoria: 8 MB PSRAM + 8 MB Flash integrada
  • Display: ST7789V2 TFT 1.14" — 135 x 240 pixels, SPI
  • Teclado: 56 teclas QWERTY com teclas de funcao
  • Audio: Speaker 1W + Microfone PDM SPM1423
  • Wireless: WiFi 802.11 b/g/n + BLE 5.0
  • IR: Emissor infravermelho 940nm (pino GPIO44)
  • Bateria: 120mAh interna (slot para bateria externa ate 2000mAh)
  • USB: USB-C com CH9102F para programacao e carga
  • Expansao: Conector M5Stack Bus + header GPIO

Codigo — Lendo informacoes do sistema

#include <M5Cardputer.h> void setup() { // Inicializa todos os perifericos do Cardputer auto cfg = M5.config(); M5Cardputer.begin(cfg, true); // Configura o display M5Cardputer.Display.setTextColor(WHITE); M5Cardputer.Display.setTextSize(1); M5Cardputer.Display.setCursor(5, 5); // Exibe informacoes do chip M5Cardputer.Display.println("=== Cardputer Info ==="); M5Cardputer.Display.printf("CPU: %d MHz\n", ESP.getCpuFreqMHz()); M5Cardputer.Display.printf("Flash: %d KB\n", ESP.getFlashChipSize() / 1024); M5Cardputer.Display.printf("PSRAM: %d KB\n", ESP.getPsramSize() / 1024); M5Cardputer.Display.printf("RAM livre: %d KB\n", ESP.getFreeHeap() / 1024); M5Cardputer.Display.printf("Bat: %d%%\n", M5Cardputer.Power.getBatteryLevel()); } void loop() {}
Dica

O metodo M5Cardputer.begin(cfg, true) inicializa o display com orientacao correta para o Cardputer. O segundo parametro 'true' ativa a rotacao automatica. Sem ele, o display aparece de lado.

Exercicio

Modifique o codigo para tambem exibir o endereco MAC WiFi do dispositivo. Dica: use WiFi.macAddress() apos incluir <WiFi.h>.

Passo a Passo de Instalacao

  • 1. Arduino IDE 2.x — Baixe em arduino.cc/en/software. Instale a versao 2.x (nao a 1.8).
  • 2. Driver USB — O Cardputer usa CH9102F. No Windows, baixe em wch.cn. No macOS/Linux e automatico.
  • 3. Board Package ESP32 — Em Preferences, adicione a URL: https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json. Em Boards Manager, instale "esp32 by Espressif Systems" versao 3.x.
  • 4. Biblioteca M5Cardputer — Em Library Manager, busque "M5Cardputer" e instale a versao mais recente da M5Stack.
  • 5. Configurar board — Tools > Board > esp32 > M5Stack-Cardputer
  • 6. Configurar porta — Tools > Port > selecione a porta COM (Windows) ou /dev/cu.* (macOS)
  • 7. Upload speed — Tools > Upload Speed > 921600

Codigo de Teste — Blink do Display

#include <M5Cardputer.h> void setup() { auto cfg = M5.config(); M5Cardputer.begin(cfg, true); } void loop() { // Alterna entre preto e azul a cada 500ms M5Cardputer.Display.fillScreen(BLACK); delay(500); M5Cardputer.Display.fillScreen(BLUE); delay(500); }
Aviso Comum

Se o upload falhar com "Failed to connect", mantenha pressionada a tecla 'G' (GPIO0) no Cardputer enquanto clica em Upload no Arduino IDE. Isso coloca o ESP32-S3 em modo de boot forcado.

Exercicio

Apos o upload bem-sucedido do blink, modifique o codigo para o display alternar entre 3 cores diferentes (vermelho, verde, azul) com 300ms de intervalo cada.
